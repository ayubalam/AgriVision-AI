# AgriVision AI — Multi-Crop Leaf Disease Detection & Treatment System

An end-to-end machine learning platform that identifies multi-crop leaf diseases from uploaded images and provides detailed treatment recommendations, symptoms, and preventive measures.

## Architecture & Tech Stack
- **Frontend:** React.js, Vite, Tailwind CSS v4, Framer Motion, Lucide React
- **Backend:** Python, FastAPI, JWT Authentication, PyMongo
- **Machine Learning:** TensorFlow/Keras, Transfer Learning (MobileNetV2 / EfficientNetB0), OpenCV
- **Database:** MongoDB Atlas
